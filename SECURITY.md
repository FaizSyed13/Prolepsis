# Security

## Found a problem?

Please **don't** open a public issue for a security problem.

Instead, report it privately: go to the **Security** tab of this repo and click
**Report a vulnerability**. Only the owner can see what you send.

Please include:

- what you found and where (file, page or link),
- how to make it happen, step by step,
- what someone could do with it.

I'll reply as soon as I can and fix real problems in the next release.

## What's covered

- the public website (https://faizsyed13.github.io/Prolepsis/)
- the code in this repo, including the start files for Windows, Mac and Linux

Prolepsis never asks for passwords, broker logins or payment details. Anything
you import in "Import my trades" stays in your own browser and is never sent
anywhere. If you see a copy of the site asking for those things, it isn't ours.

## Versions

Only the latest release gets fixes.
